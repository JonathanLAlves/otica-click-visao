# Ótica Click Visão — Landing Page

Landing page responsiva, sem formulário, com conversão direta para o WhatsApp.

## Estrutura

```text
otica-click-visao/
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── script.js
└── assets/
    └── images/
        ├── logo-click-visao.png
        ├── oculos-1.jpg
        ├── oculos-2.jpg
        ├── oculos-3.jpg
        ├── oculos-4.jpg
        └── panfleto-click-visao.jpg
```

## Executar localmente

Abra a pasta no VS Code e use a extensão **Live Server** no arquivo `index.html`, ou abra o arquivo diretamente no navegador.

## Publicação no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie todos os arquivos preservando a estrutura de pastas.
3. Em **Settings > Pages**, selecione a branch principal e a pasta raiz.

## Pontos para revisar antes de publicar

- Confirmar se a promoção de R$ 49,99 continua ativa.
- Confirmar condições e disponibilidade do exame de vista com fundo de olho.
- Confirmar o endereço e o ponto de referência.
- Confirmar o horário de atendimento e incluí-lo, caso desejado.
- Substituir ou ampliar a galeria com fotos atualizadas.
- Inserir depoimentos somente quando forem reais e autorizados.
